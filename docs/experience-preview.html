Terminal commands · shown as an example, not executed by this page
$ npm install --global --ignore-scripts ./humanizer-pro-cli-0.3.0.tgz

$ humanizer-pro login
Open the emitted Humanizer PRO URL in your browser.
Approve the operation permissions there.
Wait for the terminal's connection confirmation.

$ humanizer-pro balance
→ JSON containing the actual plan and available words.

$ humanizer-pro rewrite --consent --mode academic
Pass only your selected text through standard input.
→ JSON containing humanizedText, wordCount,
  wordsRemaining and reviewNotice.

$ humanizer-pro logout
Remove this computer's saved connection.
