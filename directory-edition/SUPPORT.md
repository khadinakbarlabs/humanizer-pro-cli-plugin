# Support

Contact hello@khadinakbar.com or https://texthumanizer.pro/mcp-docs#support. Include the plugin version (directory edition 0.3.2), your Claude host, and a safe error description. Never send tokens, passwords or private passages. For connection issues, check the connector's status in your host first (`/mcp` in Claude Code). Host permission denials require a permitted setup, not disabling security.
